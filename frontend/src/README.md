# ADOW School Management System

A web app for ADOW Primary and Secondary School.

## Features
- Login by role (student, teacher, admin)
- Attendance marking
- Fee payment receipts
- Report cards with KCSE grading

## Tech stack
React + Vite, Node.js + Express, MySQL

## How to run
Backend: cd backend, then node server.js
Frontend: cd frontend, then npm.cmd run dev
